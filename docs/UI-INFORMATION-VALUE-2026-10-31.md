# بازبینی ارزش اطلاعاتی رابط — ۹ آبان ۱۴۰۵

## دامنه
قالب‌های صفحه اصلی، امروز، برنامه‌ریزی، پروژه‌ها، ارتقا، مراجعه حضوری، بازدید دوره‌ای، بکلاگ‌ها، اقدام‌ها و داشبوردهای سفارشی و اجزای مشترک نمودار/کارت بررسی شدند. این بازبینی کد و معنای نمایش است؛ مشاهده تعاملی تمام صفحات ادعا نمی‌شود.

## اصلاحات
| بخش | مشکل | اصلاح |
|---|---|---|
| همه کارت‌های شمارش | حداقل ارتفاع ۲۶۰ پیکسل بدون محتوای متناسب | اندازه عادی ۱۱۲ و کوتاه ۹۰؛ اندازه بلند همچنان قابل انتخاب |
| برنامه‌ریزی | خطوط ماه ایجاد شبیه روند عملکرد | حذف از کارت‌ها در ۰.۶.۳۷؛ نمودار مستقل دارای ماه و توضیح باقی ماند |
| نمودار مشترک در پروژه، ارتقا، اقدام‌ها و سفارشی | نمودار دایره‌ای یا ستون با تنها یک دسته | خلاصه عددی با نام دسته و همان لینک؛ بدون نمودار بی‌مقایسه |
| نمودار مشترک | پنل بزرگ برای داده خالی یا همه نامشخص | ارتفاع متناسب با پیام؛ نامشخص با صفر اشتباه نمی‌شود |
| نمودار میله‌ای مشترک | لینک رکوردها در قالب میله‌ای استفاده نمی‌شد | حفظ لینک‌ها و فیلترها، شامل دسته‌های بازشونده |
| مراجعه حضوری | لینک رفتن به برنامه‌ریزی با نام «دریافت تازه» | عنوان دقیق «مشاهده تیکت‌های برنامه‌ریزی» |
| پروژه و ارتقا | عنوان فنی View در شمارش | عنوان «این فهرست/این انتخاب» |

## نمودارهای حفظ‌شده و دلیل
- امروز: پیگیری سررسیدشده و گروه‌های معیار فعال، دارای مسیر بررسی هستند.
- بازدید: شهر برای برنامه‌ریزی سفر، مرکز برای مقایسه حجم بازدید و انجام/مانده، Release برای ماه برنامه حفظ شد. Release تاریخ انجام واقعی نیست.
- ارتقا: نگارش فعلی و مراکز با کیس منطبق برای هماهنگی اقدام مفیدند. رفع قطعی پیش‌بینی نمی‌شود.
- پروژه: وضعیت و مرحله برای توزیع پروژه‌ها حفظ شد؛ یک مرحله به معنی درصد پیشرفت نیست.
- اقدام‌ها: توزیع اقدام‌های محلی باز/بسته مفید است؛ بسته‌شدن اقدام تأیید مشتری نیست.
- صفحه اصلی و سفارشی: نمودار ماه ایجاد با عنوان و محدودیت دامنه باقی ماند؛ تاریخچه عملکرد نیست. ابزارک ذخیره‌شده کاربر حذف یا بازنویسی نشد.
- فرم‌ها، جزئیات، گریدها و تنظیمات: جزئیات شواهد برای تصمیم لازم‌اند؛ داده یا کنترل کاربردی صرفاً برای کم‌کردن صفحه حذف نشد.

## اعتبارسنجی و محدودیت
۶۲ آزمون موفق؛ سه آزمون اضافه برای شمارش/لینک تک‌دسته‌ای، تمایز نامشخص از خالی، و حفظ فیلتر لینک دسته‌های ادامه نمودار میله‌ای. توسعه ۰.۶.۳۸ فعال و HTTP 200 بررسی شد. بررسی نهایی مرورگر پس از خطای اتصال هنگام راه‌اندازی کامل نشد؛ دو تم، صفحه‌کلید و اندازه‌های مختلف نیازمند بررسی بصری‌اند. عملیاتی ۰.۶.۳۶ تغییر نکرد. منطق CRM، معیارها، جمع شمارش و ذخیره چیدمان تغییر نکردند.
