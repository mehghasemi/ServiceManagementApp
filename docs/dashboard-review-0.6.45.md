# بازبینی سراسری داشبوردها — ۰.۶.۴۵

تاریخ: ۱۳ آبان ۱۴۰۵. دامنه: اجزای مشترک داشبوردهای ثابت و سفارشی؛ بدون تغییر محاسبات تجاری، View، معیار، داده یا مالکیت چیدمان.

| ایراد | اصلاح |
|---|---|
| فاصله‌های شبکه ۳۶ستونه حداقل ۴۲۰ پیکسل عرض می‌گرفت | فاصله انعطاف‌پذیر و قواعد مبتنی بر عرض ظرف؛ در موبایل تک‌ستونه |
| ابزار ویرایش در تمام کارت‌های سفارشی فضا می‌گرفت | کنترل‌های جمع‌شونده و حالت نمایش/بازگشت به طراحی |
| ارتفاع انتخابی نمودار سفارشی اعمال نمی‌شد | ارتفاع محدود بخش نمودار مطابق انتخاب و نمای بزرگ مستقل |
| فیلترهای بالای صفحه پس از انتقال کارت‌ها پایین می‌رفتند | حفظ فرم‌های سطح صفحه پیش از شبکه |
| نمودار زمانی برنامه‌ریزی نسخه تکراری بدون انتخابگر داشت | استفاده از قالب مشترک و انتخاب بازه جمع‌شونده |
| گروه‌های طولانی کارت‌ها را بسیار بلند می‌کردند | پیمایش داخلی و سقف ارتفاع متناسب با انتخاب |
| ویرایش شرط تکی می‌توانست شرط را حذف کند | تبدیل شرط تکی به گروه بدون حذف شرط |
| نام خالی دسته باعث برچسب نامفهوم می‌شد | استفاده از نام مشتری موجود یا «نامشخص» |

## شواهد
۸۶ آزمون سرور در دیتابیس آزمایشی مستقل موفق؛ کنترل نحوی دو فایل JavaScript موفق. مرورگر توسعه در عرض ۱۲۸۰ و ۳۹۰ پیکسل بررسی شد. در عرض ۳۹۰، داشبورد بازدید ابتدا شبکه ۴۲۰ پیکسلی داشت؛ پس از اصلاح عرض شبکه ۳۵۵ و عرض سند ۳۷۵ بود و بیرون‌زدگی حذف شد.

صفحات برنامه‌ریزی، پروژه‌ها، بازدید دوره‌ای، مراجعه حضوری، ارتقا، امروز، بکلاگ‌ها و پیشنهادها در عرض ۳۹۰ بیرون‌زدگی افقی سند نداشتند. داشبورد سفارشی نیز دو نمودار و کنترل‌های جمع‌شونده را بدون بیرون‌زدگی نمایش داد. حالت نمایش کنترل‌ها را پنهان کرد و بازگشت به طراحی آن‌ها را برگرداند؛ نمای بزرگ باز و بسته شد.

## حدود بررسی
تصویر و بررسی تعاملی حالت تاریک انجام شد؛ بررسی نهایی مجدد حالت روشن به‌دلیل در دسترس نبودن اتصال مرورگر کامل نشد. آزمون جامع صفحه‌خوان، همه ترکیب‌های ممکن نمودارساز و دسترسی از رایانه دوم انجام نشده است. عدم بیرون‌زدگی صفحه به معنی حذف پیمایش داخلی جدول یا نمودارهای پرتعداد نیست. داده و چیدمان‌های شخصی خودکار بازنشانی نمی‌شوند. این اصلاحات ادعای رفع تمام مشکلات احتمالی داشبورد یا انطباق کامل دسترس‌پذیری نیست.
